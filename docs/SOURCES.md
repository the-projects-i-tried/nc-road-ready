Build assembled September 19, 2026. Road Ready is independent practice software, not an official NCDOT question bank. All questions and explanations are newly authored/adapted practice text; the full handbook is not redistributed.

The official testing page distinguishes written traffic-law/safe-driving knowledge from traffic-sign recognition. Road Ready mixes these for practice. It does not claim that its 25-question check is an exact official exam or that any app score predicts licensing success.

## What was deliberately not claimed

Earlier chat statements about quiz scores were not imported as measurements. The browser begins with no performance evidence. An earlier assistant statement that a handbook rule was verified is not itself source verification. The current full-handbook PDF was not silently substituted with a third-party preparation site. No invented PDF page, SHA-256, publication date, or “verified today” label was attached to the unavailable document.

Some prior-chat items were omitted rather than treating every prior answer as reliable source material. New variants revisit selected concepts instead of claiming unlimited independent facts. Outstanding review is visible in the landing-page notice, About page, answer feedback, and [rule review queue](CONTENT_REVIEW.md).

## Before describing the full bank as verified

Retrieve the current PDF, preserve a local verification record with document date/version or hash, inspect all relevant pages and figures, and review every part of each question. Correct or retire ambiguous material. Update both item-level and concept-level review status only after checking it; keep a review note in version control. The handbook and traffic laws can change, so this is an ongoing editorial responsibility rather than a one-time software test.
